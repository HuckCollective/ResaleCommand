## ✅ JOIN-REQUEST HARDENING: SERVER-ONLY `join_requests` COLLECTION, SIGNED LINKS, EMAIL VERIFICATION & DRAWER-FIRST STATUS PAGE (Nov 9, 2026 — `alpha-1`)
- **Why**: applications used to live in the shared `manifests` collection with a guessable doc ID (`sha256(email)`), browser-side writes, and same-email overwrites that reset status. They now live in the dedicated **server-only** Appwrite collection **`join_requests`** (no client permissions; created by a self-deleting `scratch/` script, the one legacy test record migrated and removed from `manifests`; backup in `scratch/backups/`). In dev the collection resolves to `join_requests_dev` via `resolveCollectionId`.
- **API (`src/pages/api/join-request.ts`)**: single writer. Public actions `submit | status | verify | update | resend | reply | accept` use **HMAC-signed links** (`src/lib/joinLinkTokens.ts`: `t` = view token returned to the submitting browser, `v` = verify/owner token that is ONLY emailed). Steward actions `list | count | decide | link` require an Appwrite JWT (`X-Appwrite-JWT`) from a team owner / `admin` label (`requireSteward` in `src/lib/joinRequestsServer.ts`). Same email never overwrites (owner just gets their link re-sent, max 1/hour); honeypot + min-form-time + disposable-domain list + 150-pending cap; **stewards are only emailed after the applicant verifies** (double opt-in); edits never touch status/steward fields; email is locked after verification.
- **Reminder cron (`src/pages/api/join-reminders.ts` + `vercel.json`)**: daily; one reminder at 24h for unverified applicants, silent archive (`decisionKey: expired_unverified`) after 7 days. Requires `CRON_SECRET` env var in Vercel. Set `JOIN_LINK_SECRET` (long random string) in Vercel too (falls back to a key derived from `APPWRITE_API_KEY`).
- **UX**: new reusable `src/components/common/SlideOverDrawer.vue` (documented in `ux-design-system-taxonomy`, mounted client-side via `v-if="mounted"` to prevent SSR `<Teleport>` hydration mismatch). `/coop` "Connect With Us" opens in the drawer; submit redirects straight to `/signup?invite=…&t=…` (status page) with a persistent **"Check your inbox"** card + resend countdown until verified; stepper `Verify Email → Steward Review → Invite Approved → Account Active`; read-only summary card; **Edit My Selections** reopens the form in the same drawer. Steward panel (`JoinRequestsPanel.vue`) includes an inline **Confirm Approve & Send Invite** guard (`confirmApproveId`), hides the decision bar while typing a steward question (`Enter` sends the question), provides a 1-click **`↩️ Back to Review`** (`reopen`) button on approved invites, and shows a **Non-Production Host Banner** on `localhost` / `alpha.*` letting stewards toggle whether outbound email links point to the current test host (`🧪 localhost:4321`) or production (`🌐 works.thehc.llc`).
- **No CAPTCHA yet** (deliberately deferred; Turnstile can be added to `ConnectWithUsForm.vue` later).
